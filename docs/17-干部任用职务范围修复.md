# 干部任用职务范围修复

版本日期：2026-10-31。对应职务玩法扩展后的干部任用规则。

候选人必须具有与本级岗位相符的现任职务与履历。能力、好感、专项培养或已完成考察，均不能代替任职层级要求。

| 玩家职务 | 干部台账与任用范围 |
| --- | --- |
| 网点负责人 | 本网点员工与业务骨干 |
| 支行行长 | 所辖网点、专业团队及基层后备 |
| 二级分行行长 | 所辖支行及二级分行部门干部；普通员工不能直接越级任为支行行长 |
| 一级分行行长 | 班子、所辖二级分行及直属支行主要负责人；班子人选另需二级分行或一级分行部门层级履历 |
| 总行行长 | 总行班子、一级分行主要负责人及总行部门干部；网点及普通支行干部不进入本级候选池 |

总行任用面板明确列出重点一级分行的行长岗位，保留原有区域标识和经营数据。候选名单显示每个人的现任职务，包括尚未考察而禁用的人选。一级分行和总行的交流干部沿用已有同级负责人角色。

“当前管理”“本级后备”“本级全部”均受同一范围限制，培养、考察、谈话和新增项目牵头人也使用本级名单。任用提交时再次检查职务，即使弹窗打开后人选发生岗位变化，也不能通过旧选项越级任用。

基层旧部和培养履历继续保留在人脉簿；旧部实际升到相应职务后，可以进入本级候选池。在总行部门工作不等于担任部门负责人，名称含“行长”的秘书岗位也不视作行长履历。

## 旧存档

存档键与版本保持不变。已生效的任命不撤销，岗位、项目、贷款、历史培养和合作关系不清空；已付费的培养和历史承办项目继续执行。使用上一发布版实际生成的存档，验证这些记录在加载、结算、保存和重读后保留。
