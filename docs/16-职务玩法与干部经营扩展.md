# 职务玩法与干部经营扩展

版本日期：2026-10-31。发布目标：`Lynch715/bank-career-simulator` 的 `main` 分支及 GitHub Pages。

本轮按讨论增加各职务的经营内容，并提高干部任用、班子协调和职场关系的份量。沿用现有纸墨界面、角色立绘、考核及处分复任规则。

## 各职务新增内容

| 职务 | 经营机制 | 新项目 |
| --- | --- | --- |
| 网点负责人 | 养老、商户、财富、社区四种经营特色；员工专项培养 | 老街商户收款、社区养老服务、写字楼白领拓客 |
| 支行行长 | 年度专项资源配置；零售、风险、运营专业团队；重点客户竞标 | 学校综合服务、冉记连锁资金归集、园区企业代发迁移 |
| 二级分行行长 | 片区热度变化；产业链经营及集中风险；薄弱机构帮扶 | 柑橘加工与冷链、工业园食品产业链、薄弱支行整顿 |
| 一级分行行长 | 机构与副行长考察任用；牵头协办分工；联合项目与改革 | 汽车配套企业联合服务、全市医疗机构综合服务、公共事业缴费平台、集中运营中心 |

共17个新增项目。原有客户、对公看板、战略项目、审批、不良处置等操作仍可使用。

## 干部与关系

- 专项培养按回合完成，消耗费用与行动点；专业方向提高对口项目执行能力。培养中的干部承接已有项目会有执行折扣。
- 新入口任用干部须先完成有效期内的履职考察，不能同时占用两个当前岗位；现任旧档干部保留岗位，不要求重新考察。
- 任用后一年进行履职观察评价，记录岗位匹配情况；不合适的人选提示帮扶或调整，不自动删除角色。
- 人才记录跨职务保存，包含专项培养、考察、任用和履职评价。
- 具体同事之间的合作关系单独保存。共享成果、确定分工和解决争议能改善合作；偏向牵头人会影响协办者的关系及后续执行。
- 定期议事涉及资源分配、成果认定、后备干部推荐；在有相关人员或项目时绑定到具体角色。未参与新玩法的旧策略不会被新增待办自动扣分。
- 支行、二级分行、一级分行及总行副行长过渡期各增加一项关键决策，经验带到下一关；不额外增加年龄与回合数。过渡中断存档可以续玩。

## 项目与经营结果

启动前选择牵头人及承办单位，确认后扣费。每回合按专业、能力、关系、工作负荷和协调状态推进；执行不足、方案待定、协办争议都会暂停项目，并在报告与日志中提示。

项目在试点阶段有实施方案选择：客户竞标比较同业方案与客户偏好；产业链选择覆盖与集中程度；协同项目选择收益分配；改革选择人员安置和迁移方式。竞标未获主办资格会缩小经营回报。

落地项目产生当期及后续经营收益。一级分行和总行新项目占用现有风险加权额度，资本不足不能启动；完成或终止释放额度。终止不返还前期费用，本任期不能反复启动。

总行期限策略可选均衡、增加储备或增加长期资产。长期资产提高收益并消耗流动性；流动性低于门槛会持续增加应急资金成本并影响董事会支持，储备策略可以逐步修复。属于游戏经营模型，不代表现实监管计量。
