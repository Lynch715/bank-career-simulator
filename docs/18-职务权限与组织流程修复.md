# 职务权限与组织流程修复

针对各职务仍有越级管理、旧入口绕过新规则和重大事项立即生效的问题，统一权限与任免服务，补充可存档的报批、筹建和分期实施流程。

## 权限与干部任用

- 新增玩法与原有行动均检查职务、经营阶段和撤职状态。撤职整改期间暂停干部、培养、项目、议事与资源安排，保留客户维护及厅堂服务。
- 支行、二级分行旧任免入口调用同一任用服务，统一职务范围、能力门槛、有效履职考察、培养状态、不得兼占其他岗位及任后观察。
- 二级分行增加公司、零售、风险、运营、人力五个本部负责人岗位；营业部使用总经理职务。
- 新任期运营部和营业部分设负责人。旧档已有兼任保留并明确展示，增加履职负荷；补任其中一个岗位后解除对应兼任，保留另一个职务。
- 一级分行、总行的新干部任用先提出建议，下一回合组织审议及任免报批，获批后再执行任命。考察过期、人选退休、改任、岗位变动或行动点不足时禁止实施，不扣资源。

## 总行组织与治理

- 独立建立36家一级分行，每家有自己的负责人和经营份额，七大区仅作经营汇总与调研范围。大区内份额采用均分的游戏模型，并保持各区原有总份额及全国合计不变。
- 单一分行行长能力只作用于该分行份额；区域增长按所属分行加权，不再以一位省分行行长控制整个大区。
- 原大区任命映射到对应一级分行，原地区记录保留，历史承办单位标识继续可用；基层旧部不再参与总行直属下属声望及全国行长会议效果。
- 总行“治理支持”由董事会支持和监管评价组成，退休宋文远的私人关系不再作为正式上级信任。陆明远在任时明确为董事长，退休后由继任者主持董事会；私人关系及退休剧情继续保留。

## 授信与重大事项

以下授权数值是游戏参数，不代表现实银行的法定或实际授权：

- 支行小微600万元、对公1000万元以内的非高风险申请按本级授权办理。超金额或尽调已识别高风险先报上级贷审会，收到批复后才放款并确认收入。按钮不根据隐藏的真实违约风险层级透露答案。
- 二级分行平台项目分为补齐材料报批、明确违规绕行、拒绝三个选择。正规路径需上级审查并占用额度；额度不足可继续向上申请配套额度，额度获批与实际放款分别办理。
- 违规绕行保留原风险玩法，界面明确标记绕过审批、突破额度及合规风险，不再将它呈现为普通审批权限。
- 网点开撤：提出规划 → 上级批复 → 筹建或客户迁移 → 次回合验收。建设费在启动筹建时扣一次，验收前不挂牌、不减少既有网点或客户存款。
- 总行机构改革：方案报批 → 董事会审议及后续报批 → 试点及人员安置 → 分批推广 → 完成后确认费用节约。本任最多完成一次。
- 二级资本债：提交董事会审议及发行报批，获批后再办理到账，保留本任最多两次限制。
- 协调度、董事会支持与合规状况影响审议结果。批复不自动等于任命、放款、建成或发行到账；待审及获批未执行方案可以撤回。

## 存档兼容

存档键仍为 `thsz_save`，版本仍为4。只补充 `biz.career.approvals`、审批序号、月初处理标记和总行一级分行等字段，不重置玩家的职务、年龄、资金、行动点、贷款、已执行任命、项目或培养记录。

待审、获批、实施中、已完成、退回、撤回状态均存档。按回合和状态处理，防止重读、重复点击或重复调用月初流程造成重复开店、放款、任命或资本到账。历史已完成的改革和发行不重新执行。

## 验证

专项回归见 `tests/24-authority.js`，覆盖五级真实旧档、新旧任免入口、撤职、失效批复、零额度融资、重复入账、实施中存读档及界面点击路径。其余原有回归中，“直接完成”的旧断言已改为检查实际审批和实施阶段，经营及结局约束继续保留。

本次浏览器验收使用 Codex In-app Browser、独立 localhost 端口及测试存档，覆盖五级界面、桌面布局与390像素手机布局；没有读写玩家实际游戏存档。回归日志与截图保存在 `docs/qa/20261031-authority-*`。

最终验证：24组全部通过，其中权限及审批专项75项、五级台账界面49项、职务范围34项；60局无头冒烟与900局多策略校准通过。存档格式、存档键及原有晋升校准门槛保持不变。
